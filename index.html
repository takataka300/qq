Azani KCSE Computer Project

Azani is a complete KCSE Paper 3 Computer Studies project — a school-management style information system covering student registration, fees, marks entry, report generation and backup. It is fully compliant with the KNEC Paper 3 marking rubric: problem definition, user requirements, design (DFDs, ERDs), implementation (Microsoft Access / VB), testing, user manual and documentation are all included.

  • Complete documentation booklet (~60 pages, ready for printing)
  • Functional Microsoft Access database with forms, queries, reports & macros
  • Sample data + filled report templates (matches KNEC marking scheme)
  • Entity Relationship Diagram (ERD) and Data Flow Diagrams (DFDs)
  • Step-by-step user manual with screenshots
  • Editable — change the school name, logo, colors before submission
